=====================HOSPITAL==================================

# IMPLEMENT HOSPITAL ADMIN DASHBOARD

Read `BLOOD_BANK_PLATFORM_PLAN.md` completely before making changes.

Implement the **Hospital Admin Dashboard** for the existing multi-tenant Blood Bank SaaS platform.

## IMPORTANT

This dashboard belongs to ONE hospital tenant.

The Hospital Admin must only see data belonging to their organization.

Do not redesign the landing page or unrelated pages.

Reuse the existing authentication, organization context, API utilities, database structure, CSS/design system, and frontend architecture.

Do not create React/Next.js.

---

Use the same professional SaaS design language:

* White / light gray background
* `#DC2626` primary red
* `#111827` dark text
* `#16A34A` success
* `#D97706` warning
* `#2563EB` information
* Inter-style typography
* Rounded cards
* Subtle borders
* Soft shadows
* Professional tables
* Clean charts
* Consistent spacing
* Accessible contrast

All stakeholder dashboards must visually belong to the same platform.
