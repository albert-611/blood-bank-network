# TASK: Migrate Blood Bank Platform from MySQL/XAMPP to Supabase PostgreSQL

## Objective

Migrate the existing **Blood Bank Platform** from MySQL/XAMPP to **Supabase PostgreSQL** so the application can be deployed using:

```text
Frontend + Node/Express API → Vercel
Database → Supabase PostgreSQL
```

The application currently uses MySQL through `mysql2`. Replace the database layer with PostgreSQL while preserving all existing application functionality.

---

# IMPORTANT RULES

1. **DO NOT rebuild the application from scratch.**
2. **DO NOT change the frontend design or UI unless required for compatibility.**
3. **DO NOT remove existing features.**
4. **DO NOT change the application's business logic unnecessarily.**
5. **DO NOT change authentication/RBAC behavior unless PostgreSQL compatibility requires it.**
6. **DO NOT remove organization/tenant isolation.**
7. **DO NOT hardcode Supabase credentials anywhere in the source code.**
8. **DO NOT commit `.env` or production secrets.**
9. **DO NOT blindly replace every occurrence of `mysql` with `postgres`.**
10. First inspect the entire repository and identify every MySQL-dependent part.
11. Make changes incrementally and verify each major change.
12. Preserve the existing test suite and update only database-specific tests/configuration when necessary.
13. Keep the application using the existing **Node.js + Express.js + Vanilla JS + HTML/CSS/Tailwind** architecture.
14. Do not introduce React, Next.js, MongoDB, Docker, microservices, GraphQL, Redis, or unnecessary new infrastructure.

# PHASE 5 — CONVERT SQL QUERIES

PostgreSQL uses:

```text
$1
$2
$3
```

instead of MySQL's:

```text
?
```

Convert all parameterized queries safely.

Example:

MySQL:

```js
connection.execute(
  'SELECT * FROM users WHERE email = ?',
  [email]
);
```

PostgreSQL:

```js
pool.query(
  'SELECT * FROM users WHERE email = $1',
  [email]
);
```

Do NOT concatenate user input into SQL.

Maintain parameterized queries everywhere.

# PHASE 6 — INSERT ID HANDLING

Find every place where the application relies on MySQL:

```text

```

Replace it with PostgreSQL-compatible behavior using:

```sql

```

```sql

```

Update the JavaScript code to use the returned row.

Do not break relationships between newly created records.
